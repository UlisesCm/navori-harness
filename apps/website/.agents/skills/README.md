# Skills de animación de la landing

Copias con el contenido íntegro de las skills oficiales de [GreenSock](https://github.com/greensock/gsap-skills), obtenidas del commit `aed9cfd3277740755f6bfc1155c7aa645403b760`. Sólo se normalizaron espacios al final de línea:

- [gsap-core](gsap-core/SKILL.md): API, transforms, SVG y movimiento reducido.
- [gsap-timeline](gsap-timeline/SKILL.md): coreografía, etiquetas, reproducción y búsqueda temporal.
- [gsap-performance](gsap-performance/SKILL.md): rendimiento y limpieza de animaciones.

La [licencia MIT del proveedor](LICENSE.gsap-skills) aplica a estas tres copias. La dependencia de ejecución se declara por separado en `apps/website/package.json` como `gsap@3.15.0`.

Se conservan junto a la aplicación para que el trabajo pueda retomarse sin depender de la instalación global de una máquina. Antes de actualizarlas, comparar con su origen y revisar el cambio; no son assets del core de Navori.
