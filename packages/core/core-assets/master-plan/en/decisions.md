# DECISIONS.md template

No decisions yet: the file reads literally `No decisions`.

Each decision is a `## D<n>` heading (consecutive from `D1`) with four fields:

## D1

- Question: <the question asked>
- Chosen: <chosen option>
- Discarded: <the other options>
- Date: YYYY-MM-DD

From stage 2 onward (R52), a question about a deferred part from the last closed stage names `<NN-slug>/P<n>` in its text.
